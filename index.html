Conexión con Google Drive

Para leer la carpeta privada de Drive necesitas un Client ID de Google (gratis). Se configura una sola vez y queda guardado en este dispositivo.

Cómo obtenerlo (5 min):
1. Entra a console.cloud.google.com y crea un proyecto.
2. En "APIs y servicios" → Biblioteca → activa Google Drive API.
3. En "Credenciales" → Crear credenciales → ID de cliente de OAuth → tipo Aplicación web.
4. En "Orígenes de JavaScript autorizados" agrega la URL de tu app (ej: https://alvarofernandomora-tech.github.io).
5. Copia el Client ID y pégalo aquí abajo.
